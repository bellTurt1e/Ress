Turtle Knight / Software Engineer · January–May 2022

A small turtle. A big cleanup.

Unity / C# / Git / Game development

My contributions

  • Built UI elements, animations, and sprite sheets.
  • Resolved physics and animation bugs.
  • Wrote event-based C# scripts for health systems, boss animations, and event triggers.
  • Collaborated through Git and GitHub branch management.
