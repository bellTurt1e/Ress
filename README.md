# Raymond Bell — personal portfolio

Static HTML, CSS, and a small progressive-enhancement script. Hosted with GitHub Pages at the existing custom domain in CNAME.

## Preview

Run a static HTTP server from the repository root (for example, python -m http.server 8000), then open http://localhost:8000.

## Update content

- index.html: current role, experience, and project gallery.
- location.html: biography.
- contact.html: social and video links.
- Pages/: individual case studies and original portfolio entry point.
- css/style.css: shared responsive design.
- js/script.js: accessible project filters; every project remains visible without JavaScript.

Existing media, PDFs, and URLs are retained. PDFs are explicitly labeled as archived on Pages/portfolio.html. No build process or third-party runtime dependencies are required.
